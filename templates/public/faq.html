General Overview

DevWorkspace is an educational web application designed for students and developers to learn programming languages (Python, HTML, CSS, JavaScript), test code in an in-browser workspace, manage project files, and maintain snapshot backups.

Yes, DevWorkspace is open and free for students and developers as part of an academic IT research initiative.

Account & Security

In this current frontend phase, authentication state is simulated using browser localStorage. When connected to the Python Flask + SQLite backend later, sessions will be managed via secure HTTP-only session cookies and JWT tokens.

Learning & Quizzes

Yes! All quizzes can be retaken at any time. You can review detailed question breakdowns, explanations for incorrect answers, and track your mastery score.

Workspace & Projects

No local installations are required. The web workspace provides an in-browser code editor and client-side simulation engine so you can code directly from any device.

Backup & Restore

DevWorkspace creates compressed archive snapshots of your workspace files and notes. When restoring, the preview dialog detects naming conflicts and lets you choose between Skip, Replace, or Rename policies.

Admin Management

Instructors log in using administrator credentials (demo: admin@devworkspace.io / Admin123!). The Admin Portal provides curriculum CRUD management, user status toggling, and global activity audit logs.
